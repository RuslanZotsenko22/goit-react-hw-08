# 📱 Project: Phonebook App (React + Vite)

## 📌 Description
This is a web application for managing personal contacts. Users can register, log in, and manage their own contact list securely. The app is built with React and Vite, offering fast performance and a clean developer experience.

## 🧰 Tech Stack
- **React** — UI library
- **Vite** — fast build tool
- **JavaScript (ES6+)**
- **HTML5 / CSS3**

## 🔍 Key Features
- 🔐 **User Authentication**: register and log in functionality
- 📇 **Contact Management**: add, update, delete your own contacts
- ⚡ **High Performance**: thanks to Vite bundler

## 🚀 How to Run Locally

1. Clone the repository:
```bash
git clone https://github.com/RuslanZotsenko22/goit-react-hw-08.git
```

2. Navigate to the project folder:
```bash
cd goit-react-hw-08
```

3. Install dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm run dev
```

5. Open in your browser:
```
http://localhost:5173
```
